# Identidad AH, web y medios del portafolio

Este documento establece **cómo presentaremos los nuevos casos**. No implica que los archivos históricos del autor ya estén publicados aquí.

## Diseño

Los proyectos Power BI usarán como referencia una identidad AH con:

- Encabezado `#12263E`, navegación `#174A79`, acento `#248CDD` y fondo claro `#F3F7FC`.
- Tipografía legible, navegación funcional, indicadores jerarquizados y visuales justificados.
- El diseño se adapta al caso: no copiar páginas, medidas o filtros sin necesidad.

La última web de referencia del autor emplea una variante **oscura** (fondo `#071323`, superficies `#0E2136`, acento `#4CBBFF`). El diseño de la nueva web **aún no está cerrado**.

## Qué podrá consultar un visitante

| Formato | Visualización prevista |
| --- | --- |
| **HTML/CSS/JS** | Portal navegable, publicado posteriormente con GitHub Pages |
| **PDF** | Vista de dashboards y resúmenes ejecutivos dentro del navegador |
| **PNG/JPG** | Infografías y capturas dentro de README, galerías y página web |
| **Notebook** | Código, exploraciones y resultados legibles en GitHub |
| **PBIP** | Archivos de proyecto para apertura en Power BI Desktop; **no** se ejecutan dentro de GitHub |
| **CSV y otros datos** | Descarga/reproducción solamente tras verificar permisos y privacidad |

Para el futuro sitio web se preferirá **HTML, CSS y JavaScript sencillos**, reutilizando principios visuales existentes sin incorporar frameworks innecesarios.

## Reglas

- La galería mostrará únicamente casos y materiales **revisados y autorizados**.
- Los PDF e infografías deben ser legibles, accesibles y coherentes con el análisis documentado.
- Las referencias originales de Santander, VinkOS y FlyAcross se conservan **fuera de este repositorio público** hasta que haya una versión apropiada para difusión.
- No prometer dashboards interactivos desde PDF; Power BI embebido requerirá una evaluación separada de privacidad y licencias.
- La web se publicará solo cuando tenga contenido real, enlaces probados y revisión de derechos.
