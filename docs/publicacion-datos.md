# Datos, privacidad y condiciones de publicación

## Principio

El objetivo es publicar **datasets y artefactos reproducibles** cuando sea posible, pero **público no significa automáticamente redistribuible**. Tampoco basta con eliminar logotipos o anonimizar nombres para adquirir derechos sobre un archivo.

## Ficha mínima por dataset

Registrar, antes de publicar:

| Campo | Contenido requerido |
| --- | --- |
| Fuente primaria | Organización, enlace original, origen o método de obtención |
| Archivo / versión | Nombre, fecha de descarga y versión identificable |
| Licencia o condiciones | Permisos específicos de descarga, uso, modificación y redistribución |
| Atribución | Créditos, licencia y referencias exigibles |
| Datos personales | Evaluación de identificadores directos e indirectos |
| Transformaciones | Limpieza, anonimización/síntesis y cambios relevantes |
| Integridad | Si resulta pertinente, SHA-256 de la versión publicada |
| Decisión | Publicable / no publicable / pendiente de verificar, con motivo |

## Reglas de decisión

- Si la fuente y licencia permiten redistribución y los datos son seguros: publicar el dataset autorizado y atribuirlo.
- Si el material es sensible, contractual, privado o no tiene permisos suficientes: **no subirlo**. Considerar un dataset sintético o una alternativa pública con condiciones verificadas.
- Si la procedencia o los permisos son inciertos: mantenerlo **pendiente** y publicar, cuando corresponda, únicamente instrucciones para conseguir una fuente legítima.
- No incluir credenciales, contraseñas, tokens, datos privados, documentos de selección confidenciales, logos ajenos no autorizados ni rutas internas.
- Distinguir explícitamente muestras sintéticas y simulaciones de información observada real.

## Artefactos visuales

Los dashboards, imágenes, PDF y materiales visuales mantienen la identidad **AH** y respetan las condiciones de uso de datos, marcas y otros recursos.
